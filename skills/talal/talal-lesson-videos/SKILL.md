# فيديو الدرس بصوت «لهجاتي» متزامن مع المشاهد

## الفكرة (اقرأها أولًا)
المعلم **لا** يرسل الصوت أولًا. الترتيب دائمًا:
1. **Claude يصمم الفيديو صامتًا** بمدد تقديرية → يرسله للمراجعة.
2. **Claude يعطي نص التسجيل** مقسومًا لملفات (جزء 1، جزء 2) بالجمل نفسها حرفيًا.
3. **المعلم يولّد الصوت في «لهجاتي»** ويرسل ملفات mp3 (ملف لكل جزء).
4. **Claude يقطّع كل ملف إلى جمله** ويبني خطًا زمنيًا جديدًا من المدد الحقيقية، فتتحرك المشاهد والترجمة والعناصر مع الصوت، ثم يخرج الفيديو النهائي.
لا تطلب منه تسجيل كل جملة في ملف مستقل، ولا تغيّر نص الجمل بعد إعطائه له (التقطيع يعتمد على عدد الحروف).

## قواعد إلزامية
- **لا موسيقى ولا إيقاع ولا دف**. الخلفية إن وُجدت: نشيد/ذكر هادئ بلا آلات، منخفض جدًا لا يغطي الكلام.
- **لا تُظهر وجوه الصحابة** ولا يُمثَّل النبي صلى الله عليه وسلم. الشخصيات المعتادة: معلم وطالب، أو أب وابنه (يوسف).
- الحوار غالبًا **باللهجة البحرينية** إن طلب المعلم، والآيات بنصها مشكولة.
- شعار المدرسة في مشهد العنوان. 1280×720، 25 إطار/ث، الحجم أقل من 30MB.

## الخطوة 1: التصميم الصامت
- اكتب `LINES = [(المتكلم 'f' أو 's', نص الترجمة HTML مع <b> للكلمات المهمة, رقم المشهد, [(نسبة من مدة الجملة 0–1, id عنصر يظهر)])]`.
  - جمل قصيرة إلى متوسطة؛ الجملة الطويلة جدًا تُقسم. كل مشهد 1–3 جمل.
  - الأحداث `(0.3, 'h1')` تجعل العنصر يظهر عند 30% من الجملة (مثل كلمة أو آية أو أيقونة).
- المشاهد HTML/SVG (div.sc لكل مشهد)، والحركة كلها في دالة `render(t)` بالجافاسكربت: شفافية المشاهد، الترجمة مع اسم المتكلم، فم يتحرك للمتكلم، ظهور العناصر في أوقات الأحداث.
- بدون صوت: مدة الجملة = عدد الحروف ÷ 13.
- التصوير: Playwright يستدعي `render(i/FPS)` لكل إطار ويصوّر JPEG، ثم ffmpeg يجمعها. صوّر أولًا لقطات عند أزمنة معينة للفحص قبل الإخراج الكامل.

## الخطوة 2: نص التسجيل للمعلم
أعطه رسالة جاهزة بهذا الشكل:
- «الجزء 1 (ملف واحد):» ثم الجمل مرقمة بالترتيب، **بدون HTML**، كما ستظهر حرفيًا.
- اقسم الحوار إلى جزأين أو ثلاثة (6–8 جمل لكل ملف) لأن «لهجاتي» له حد للطول.
- اطلب منه: نفس ترتيب الجمل، **وقفة قصيرة واضحة (نصف ثانية إلى ثانية) بين الجمل**، وأن يسمّي الملف بالجزء (a.mp3 و b.mp3). إن كان للمعلم والطالب صوتان مختلفان فليولّد كل جملة بصوت شخصيتها في نفس ملف الجزء بالترتيب.

## الخطوة 3: التقطيع والمطابقة (عند استلام mp3)
1. انسخ الملفات المرفوعة إلى مجلد العمل.
2. اكتب `parts.json`: `[{"file":"a.mp3","lines":[نصوص جمل الجزء 1 بلا HTML]}, {"file":"b.mp3","lines":[...]}]`.
3. شغّل `python voice_sync.py parts.json segs.json` (الكود في الملحق) → يطبع لكل جملة بدايتها ونهايتها ومعدل الحروف/ثانية.
4. **راجع الجمل المعلَّمة «راجع»** (معدلها شاذ = الحد غالبًا خطأ):
   - `python voice_sync.py --sil a.mp3 -30dB 0.08` يعرض كل الوقفات بعتبة أدق.
   - اختر الوقفة التي تجعل المعدل قريبًا من بقية الجمل، وعدّل الحدين في `segs.json` يدويًا.
   - إن نقص عدد الوقفات عن عدد الجمل: اطلب من المعلم إعادة الجزء بوقفات أوضح.
5. ابنِ الخط الزمني من المدد الحقيقية: `INTRO 5.5 ث` للعنوان، `LEAD 0.7` قبل أول جملة في المشهد، `GAP 0.45` بين الجمل، `TAIL 0.8` بعد آخر جملة في المشهد، `OUTRO 6` للخاتمة. كل جملة تُقص من ملفها (ffmpeg إلى s16le 24kHz أحادي ثم numpy) وتُلصق في مسار صوت WAV واحد، والترجمة تبدأ قبل الصوت بـ 0.15 ث وتنتهي بعده بـ 0.25 ث، والأحداث عند `بداية الجملة + نسبة × مدتها`.
6. صوّر الإطارات واجمعها مع الصوت: `ffmpeg -framerate 25 -i frames/%05d.jpg -i voice.wav -c:v libx264 -pix_fmt yuv420p -crf 23 -c:a aac -b:a 160k -shortest out.mp4`.

## الفحص قبل الإرسال
- مدة الفيديو = مدة الخط الزمني تقريبًا، والصوت لا ينقطع وسط جملة.
- صوّر 4–6 لقطات عند بدايات جمل مختلفة وتأكد أن الترجمة الظاهرة هي الجملة المسموعة.
- الحجم < 30MB (وإلا `-crf 26`).
- أرسل نسختين: `فيديو_<الدرس>_بالصوت.mp4` و `فيديو_<الدرس>_صامت.mp4`.

## ملحق: voice_sync.py
احفظ هذا الكود باسم voice_sync.py في مجلد العمل.

```python
import subprocess, re, json, sys, math

def sil(f, noise='-32dB', d=0.18):
    o = subprocess.run(['ffmpeg', '-v', 'info', '-i', f, '-af', f'silencedetect=noise={noise}:d={d}', '-f', 'null', '-'], capture_output=True, text=True).stderr
    ss = [float(x) for x in re.findall(r'silence_start: ([0-9.]+)', o)]
    se = [float(x) for x in re.findall(r'silence_end: ([0-9.]+)', o)]
    return list(zip(ss, se))

def dur(f):
    return float(subprocess.run(['ffprobe', '-v', 'error', '-show_entries', 'format=duration', '-of', 'csv=p=0', f], capture_output=True, text=True).stdout)

def W(t):
    t = re.sub('<[^>]+>', '', t)
    return len(re.sub(r'[ً-ْٰـ]', '', t).replace(' ', ''))

def dp(f, lines):
    S = sil(f); D = dur(f)
    st = S[0][1] if S and S[0][0] < 0.05 else 0.0
    en = S[-1][0] if S and S[-1][1] > D - 0.05 else D
    S = [s for s in S if s[0] > st + 0.3 and s[1] < en - 0.3]
    w = [max(1, W(l)) for l in lines]; n = len(lines); pts = [(st, st)] + S + [(en, en)]
    if len(pts) - 1 < n:
        raise SystemExit(f'{f}: الوقفات ({len(pts)-2}) أقل من الجمل ({n}) - اطلب تسجيلا بوقفات أوضح')
    R = sum(w) / ((en - st) - 0.35 * (n - 1)); best = {(0, 0): (0, None)}
    for k in range(1, n + 1):
        for j in range(1, len(pts)):
            if (k == n) != (j == len(pts) - 1): continue
            bb = 1e9; arg = None
            for i in range(j):
                if (k - 1, i) not in best: continue
                d = pts[j][0] - pts[i][1]
                if d <= 0.3: continue
                c = best[(k - 1, i)][0] + math.log(d * R / w[k - 1]) ** 2
                if k < n: c -= 0.6 * (pts[j][1] - pts[j][0])
                if c < bb: bb = c; arg = i
            if arg is not None: best[(k, j)] = (bb, arg)
    j = len(pts) - 1; k = n; seq = []
    while k > 0:
        i = best[(k, j)][1]; seq.append((pts[i][1], pts[j][0])); j = i; k -= 1
    return seq[::-1]

if __name__ == '__main__':
    if sys.argv[1] == '--sil':
        for a, b in sil(sys.argv[2], *(sys.argv[3:4]), *([float(sys.argv[4])] if len(sys.argv) > 4 else [])): print(f'{a:7.2f} - {b:7.2f}  ({b-a:4.2f}s)')
        sys.exit()
    parts = json.load(open(sys.argv[1], encoding='utf-8')); out = []; rows = []
    for p in parts:
        for (a, b), l in zip(dp(p['file'], p['lines']), p['lines']):
            rows.append((p['file'], a, b, W(l) / (b - a), l)); out.append([p['file'], round(a, 2), round(b, 2)])
    med = sorted(r[3] for r in rows)[len(rows) // 2]
    for f, a, b, rate, l in rows:
        flag = '  <-- راجع' if abs(rate - med) / med > 0.45 else ''
        print(f'{f} {a:6.2f}-{b:6.2f} ({b-a:5.2f}s) {rate:4.1f}  {l[:40]}{flag}')
    json.dump(out, open(sys.argv[2], 'w'))
```
