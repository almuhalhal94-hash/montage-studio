# OpenMontage — مشغّل

OpenMontage نظام كامل (≈160 ميغا، مئات الملفات وأدوات بايثون)، لا يُرفع كسكيل. هذه السكيل تجلبه للجلسة وتشغّله.

## 1) الجلب (أول خطوة في كل جلسة جديدة)
```bash
cd ~ && [ -d OpenMontage ] || git clone --depth 1 https://github.com/calesthio/OpenMontage.git
cd ~/OpenMontage && pip install -r requirements.txt --break-system-packages -q
```
GitHub مسموح في بيئة العمل، فلا حاجة لكروم.

## 2) التشغيل
- اقرأ `~/OpenMontage/AGENT_GUIDE.md` قبل أي عمل والتزم به (Rule Zero: كل فيديو يمر عبر pipeline من `pipeline_defs/`، واقرأ director skill لكل مرحلة قبل تنفيذها).
- لا مفاتيح API مدفوعة عنده: اختر المسارات المجانية/المحلية (Remotion/HyperFrames، FFmpeg، رسومات SVG، صور مولّدة محلياً). لا تطلب مفاتيح إلا إذا لزم فعلاً واذكر التكلفة.

## 3) قيود أ. طلال (تتقدم على أي توصية في OpenMontage)
- بلا موسيقى ولا إيقاع/دف إطلاقاً؛ الخلفية الصوتية نشيد بلا آلات أو ذكر هادئ، ولا تغطي على الحوار.
- قصص الصحابة: لا وجوه ولا ما يخالف الشرع.
- الصوت: يولّده هو في تطبيق «لهجاتي» من النص الذي تعطيه، ثم يرسل mp3 لتطابقها على المشاهد (راجع سكيل talal-lesson-videos).
- نبّهه قبل أي مهمة تستهلك توكنز كثيرة، وقلّل الأخذ والرد.
